# 📚 Sensor Academy

Sensor Academy is a modern educational learning platform designed to help students easily access study materials, video lessons, past exam papers, quizzes, and digital books in one place.

The platform is mobile-friendly, responsive, and built with a clean UI to enhance learning experience for students across different academic levels.

---

## 🚀 Features

* 📖 Past Exam Papers (Download & Filter)
* 🎥 Video Lessons (Educational Content)
* 📚 Digital Books & Study Materials
* 📝 Online Quizzes & Tests
* 🔍 Global Search System
* 👤 User Authentication (Login/Register UI)
* 📱 Mobile-First Responsive Design
* 🧭 Bottom Navigation for Mobile Users
* 🧑‍🏫 Admin Dashboard (UI Structure)

---

## ⚙️ Installation & Setup

1. Clone the repository:

```bash
git clone https://github.com/yourusername/sensor-academy.git
```

2. Install dependencies:

```bash
npm install
```

3. Run development server:

```bash
npm run dev
```

4. Open in browser:

```
http://localhost:3000
```
